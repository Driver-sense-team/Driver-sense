# 법규 룰 테이블

법규 Q&A(F8)의 근거 데이터입니다. 파일은 [data/law_table.json](../data/law_table.json)이고, 코드에서는 `kkam.engine.model.LawEntry`로 읽습니다.

서버는 이 파일을 가공 없이 그대로 내려줍니다. 행 전체를 Q&A 프롬프트에 넣으므로 **20행을 넘기지 않습니다.**

## 필드

| 필드 | 타입 | 뜻 | 예 |
| --- | --- | --- | --- |
| id | String | 고유 번호. 답변의 근거 표시에 쓴다 | `LAW-01` |
| topic | String | 주제 | `회전 전 방향지시등` |
| situation | String | 어떤 질문이나 상황에 해당하는지 | `일반도로에서 좌회전 또는 우회전할 때` |
| article | String | 법 조항 | `도로교통법 제38조` |
| summary | String | 운전자에게 말할 쉬운 설명 1~3문장 | |
| penalty | String | 승용차 기준 처분. 없으면 `해당 없음`, 미확인이면 `확인 필요` | `승용차 범칙금 6만 원, 벌점 15점` |
| sourceUrl | String | 출처 주소 | |
| disputed | Boolean | 해석이 갈리면 true. 답변에서 단정하지 않는다 | `true` |
| note | String | 확인할 내용이나 주의사항. 없으면 빈 문자열 | |

## 고칠 때 규칙

- 출처에서 확인되지 않은 내용은 지어내지 않고 `note`에 "확인 필요"라고 적습니다.
- 금액이나 조항을 바꾸면 `data/qna_eval.json`의 정답도 함께 확인합니다([tasks.md](tasks.md) 단계 15).
- 기간이 있는 항목(`LAW-06`, `LAW-07`)은 기간이 지나면 갱신합니다.
